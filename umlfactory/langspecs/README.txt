Langages ajoutés depuis le menu « Autre langage… » : un fichier <id>.json par langage (spécification : règles de
génération, outils requis, commande de vérification) et, si un outil manque sur l'appareil, <id>.install.txt
(guide d'installation écrit par le LLM, à lire et à suivre par l'utilisateur : le LLM n'exécute rien).
Ces fichiers sont des DONNÉES : aucun code n'est généré ni importé.
